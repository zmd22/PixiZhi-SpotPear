PixiZhi SpotPear

Firmware __VERSION__ for the Spotpear Ball v2 (ESP32-S3)

  1. Use Chrome or Edge on a computer. Connect the ball with a USB-C data cable.
  2. Hold the BOOT button while plugging in (the firmware uses USB for audio, so the chip must start in download mode).
  3. Click Install and pick the port that appears.

After installing

  1. Unplug and reconnect normally. The ball shows PIXIZHI SETUP with a QR code.
  2. Scan it (or join the PixiZhi Setup Wi-Fi) and choose your network.
  3. In Home Assistant: Settings → Devices & services, add the discovered PixiZhi SpotPear, and allow it to perform Home Assistant actions.
  4. Import the blueprints from the repository.

Later versions arrive as a normal firmware update in Home Assistant.
